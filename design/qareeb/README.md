# Qareeb design canvas

Visual baseline for the Qareeb marketplace, drafted from the build prompt's
concrete visual specification (colors, type, spacing, radii, semantic states).

- `build.mjs` — generates every artboard from one shared token set. Run `node build.mjs`.
- `*.dc.html` — artboards: discovery (EN / HE / AR), business detail, product
  options sheet, checkout with the village address block, business incoming
  orders (desktop), admin pending approvals (desktop), design tokens.
- `canvas.json` — artboard layout on the canvas.

All names, phones, prices and orders are sample data for the mockup only.
